## ✨ Features

- **🎨 Modern & Responsive Design**: Built with Tailwind CSS for a sleek, dark-themed aesthetic that works perfectly on all devices.
- **⚡ High Performance**: Powered by Vite for lightning-fast HMR and optimized builds.
- **🎬 Fluid Animations**: Implements **Framer Motion** for complex page transitions and scroll animations, plus **Lottie** for vector animations.
- **🖱️ Custom Interactions**: Features a custom fluid cursor and smooth scroll effects.
- **🧩 Dynamic Content**:
  - **Project Showcase**: Detailed view of selected projects with case studies.
  - **Tech Stack**: Visual representation of skills and technologies.
  - **Code Playground**: Interactive coding-themed sections.
- **📬 Contact Integration**: Fully functional contact form powered by EmailJS.

## 🚀 Tech Stack

### Core

- **[React 19](https://react.dev/)**: The latest version of the library for building user interfaces.
- **[Vite](https://vitejs.dev/)**: Next Generation Frontend Tooling.
- **[React Router v7](https://reactrouter.com/)**: For seamless client-side routing.

### Styling

- **[Tailwind CSS v4](https://tailwindcss.com/)**: Utility-first CSS framework.
- **[Tailwind Scrollbar](https://github.com/adoxography/tailwind-scrollbar)**: Custom scrollbar styling.
- **[React Icons](https://react-icons.github.io/react-icons/)**: Comprehensive icon library.

### Animations & UI

- **[Framer Motion](https://www.framer.com/motion/)**: Production-ready motion library for React.
- **[Lottie React](https://lottiereact.com/)**: Render After Effects animations on the web.
- **[React Simple Typewriter](https://www.npmjs.com/package/react-simple-typewriter)**: Typewriting effects.
- **[React Intersection Observer](https://github.com/thebuilder/react-intersection-observer)**: Monitoring visibility of elements.

## 🛠 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

Make sure you have the following installed:

- **[Node.js](https://nodejs.org/)** (v18 or higher recommended)
- **npm** or **yarn**

### Installation

1.  **Clone the repository**:

    ```bash
    git clone https://github.com/your-username/amikaSubasinghe-react.git
    cd amikaSubasinghe-react
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

### Running Locally

Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173`.

### Building for Production

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
